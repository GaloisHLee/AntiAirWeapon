# 手工烟测清单

## 安装检查

- 将 `demo/AntiAirWeapon/` 放入 RimWorld `Mods` 目录后，模组可以被正常识别。
- 模组依赖 `HugsLib`，加载顺序正确，没有缺失依赖报错。
- 进入游戏主菜单和载入存档时，不出现红字初始化错误。

## 内容检查

- `Simple AntiAirWeapon` 与 `Advance AntiAirWeapon` 能在建造菜单中出现。
- 研究项目与研究页签显示正常。
- 建筑贴图、UI 图标、音效资源加载正常。
- 中英文等现有语言键值能够正常显示，不出现明显缺失翻译键。

## 行为检查

- 简易防空炮只拦截敌对炮弹，不误击中立贸易货仓。
- 进阶防空炮只拦截敌对飞行舱，不误击友方或中立空投。
- 模组设置中新增的拦截选项可以正常显示并保存。
- `永不拦截 defName`、`总是拦截 defName`、`按敌对关系拦截 defName` 三类配置生效。

## 兼容检查

- 对没有明确派系的未知 `Skyfaller`，默认不拦截。
- 打开 `拦截未知 Skyfaller` 后，对应目标会被允许拦截。
- 第三方模组飞行物加入自定义 `defName` 配置后，行为符合预期。

## 回归检查

- 防空炮供电、冷却、射程与原始 Def 参数保持正常。
- 击落目标后不会导致地图卡死或持续红字。
- 旧存档加载该版本模组后，防空炮建筑不会直接报错消失。
