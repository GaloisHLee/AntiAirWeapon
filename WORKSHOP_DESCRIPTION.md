# AntiAirWeapon[forked]

Fork of Anti-Air Weapon by AKreedz, updated for RimWorld 1.6.

## Requirements

- Harmony
- HugsLib
- RimWorld 1.6

## Features

- Intercepts hostile overhead projectiles.
- Intercepts hostile drop pods and transporters.
- Adds configurable target rules for modded flying targets.
- Provides a searchable target selector in Mod Options.
- Supports Never Intercept, Always Intercept, and Hostile Only rule lists.
- Records recently observed airborne targets for easier configuration.
- Preserves old or missing defName entries from removed mods.
